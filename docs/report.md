## 1. SCQA 프레임워크 — 분석의 스토리 구조

| | |
|---|---|
| **S · Situation** | 역사 내외에 위치한 편의점은 바쁘게 이동하는 지하철 승하차객이 주된 고객층으로, 매우 빠른 상품 회전율이 핵심 특징입니다. |
| **C · Complication** | 아침 출근 시간에는 김밥, 샌드위치, 커피가 순식간에 동나고 퇴근 시간에는 주류와 야식류 수요가 급증하지만, 시간대별 정밀 수요 예측 실패로 매번 기회손실(결품)이나 재고 폐기가 발생함. |
| **Q · Question** | 승하차 패턴 데이터를 활용하여 역사 인근 편의점의 발주 효율과 매출을 동시에 극대화하려면 매장을 어떻게 운영해야 하는가? |
| **A · Answer** | 역별 승하차 집중 시간대 데이터를 기반으로, 출근족이 쏟아지는 오전에는 간편식을 전면 배치하고, 퇴근 시간대에는 맥주·안주류 재고를 확충하는 '시간대별 가변형 진열 및 발주 시스템'을 적용. |

## 3. OLS 선형회귀 및 통계적 잔차 진단 (Statistical Modeling)

오전 출근 시간대 유동인구 규모가 오후 퇴근 시간대 유동인구와 가지는 정량적 선형 관계를 검정하고, 개별 역사 상권의 고유한 편차를 수학적으로 도출하기 위해 OLS(Ordinary Least Squares) 선형회귀분석을 설계했습니다.

- **독립변수(X)**: 오전 출근 시간대(07시~09시) 하차 인원 (역 단위, 월평균)
- **종속변수(Y)**: 오후 퇴근 시간대(18시~20시) 승차 인원 (역 단위, 월평균)
- **통제변수(C)**: 낮 시간대(10시~16시) 총 이용객 — 역의 전반적인 규모(“큰 역은 모든 시간대에 크다”)를 대리

환승역은 노선별 행을 합산하여 물리적인 역 하나당 한 행으로 만들었습니다.

### 3.1. 통계적 상관관계 방정식

```
기준선(비교용):   Ŷ = β₀ + β₁·X
분석 모델:       Ŷ = β₀ + βₓ·X + β_c·C
```

βₓ는 낮 시간대 이용객(C)이 같은 역끼리 비교했을 때, 오전 하차가 1명 많을수록 오후 승차가 평균적으로 몇 명 많은지를 뜻합니다(상관관계). 단순회귀의 높은 R²는 대부분 역 규모 효과이므로, 분류와 해석은 모두 통제변수를 넣은 다중회귀를 기준으로 합니다.

### 3.2. 잔차(Residual) 기반의 상권 세분화 매칭 이론

다중회귀의 잔차(Residual = Y − Ŷ)는 “오전 하차량과 역 규모로 예상되는 것보다 퇴근 승차가 많은가/적은가”를 나타냅니다. 이 부호로 역을 두 유형으로 나눕니다. 단, 잔차가 0 근처인 역(|표준화잔차| < 0.5)은 분류 신호가 약하므로 별도로 표시하고, 로그-로그 모델로 다시 분류했을 때의 일치율도 함께 보고합니다.

- **퇴근집중형 상권 (Positive Residual, Residual > 0)**: 회귀 예측 모델이 산출한 기대 승차량보다 실제 퇴근 인원이 더 많은 상권입니다. 가설상 업무지구 외에 상업·여가 수요가 겹치는 지역(예: 홍대입구, 건대입구)이 해당할 것으로 예상되며, 실제 해당 여부는 스크립트가 출력하는 `station_types.csv`로 확인합니다.
  → **제안 전략(검증 필요)**: 17시 이후 주류·안주·스낵 카테고리 진열 면적 확대 및 저녁 시간대 발주 비중 상향. 확대 폭(예: 1.5배)은 매장 POS 데이터로 A/B 테스트 후 결정.
- **출근집중형 상권 (Residual ≤ 0)**: 오전 하차량과 역 규모로 예상되는 것보다 퇴근 승차가 적은 상권입니다. 가설상 퇴근 후 다른 지역으로 이동하는 비중이 큰 지역이 해당할 것으로 보이며, 마찬가지로 `station_types.csv`로 확인합니다.
  → **제안 전략(검증 필요)**: 06~10시 삼각김밥·샌드위치·베이커리·RTD 커피를 쇼케이스 상단과 계산대 동선에 전면 배치.

## 4. Claus Wilke 시각화 원칙의 도메인 적용

- **비례 잉크 원칙 (Proportional Ink)**: Fig 1의 산점도 X·Y축과 히트맵 색상 척도는 0에서 시작하도록 고정해 규모 차이가 과장되지 않게 했습니다. (잔차 플롯은 0을 중심으로 한 양·음 값이므로 예외)
- **의미 있는 색상 (Color with Meaning)**: 색은 역 유형을 나타낼 때만 사용합니다 — 출근집중형은 오렌지(`#F4A261`), 퇴근집중형은 네이비(`#2549D8`)로 Fig 1 산점도·잔차 플롯과 Fig 3 역 이름 라벨에 동일하게 적용했습니다. 히트맵 칸의 색은 이용 비중(%) 크기 하나만 인코딩합니다.
- **데이터 기반 정렬 (Order by Data)**: Fig 3은 노선·가나다 순이 아니라 이용량 상위 20개 역을 이용량 내림차순으로 정렬해 운영 우선순위가 위에서부터 읽히도록 했습니다.
- **비교 가능한 정규화**: 히트맵은 역마다 시간대별 비중(%)을 먼저 구한 뒤 평균을 내어, 초대형 역 몇 곳이 유형 평균을 좌우하지 않도록 했습니다.

### 5-1. 통제변수 반영 회귀분석 결과

기존 단순회귀(Y ~ X)는 두 변수 간 상관관계를 인과관계로 오인할 위험이 있어, 낮 시간대 총 이용객을 통제변수(C)로 추가한 다중회귀(Y ~ X + C)로 재검증했습니다.

- **단순회귀 기준선**: R² = 0.9422, slope = 0.9907
- **다중회귀 모델 적합도**: R² = 0.9815
- **오전 하차인원(X) 회귀계수**: βₓ = 0.7469 (p < 1e-100) — 낮 시간대 이용객이 같은 수준일 때, 오전 하차 1명당 오후 승차 약 0.75명 증가와 연관
- **통제변수(C) 회귀계수**: β_c = 0.119 (p < 1e-100)
- **다중공선성**: corr(X, C) = 0.7693 → VIF = 1/(1−0.7693²) ≈ 2.4. 일반적 기준(5)보다 낮아 계수 해석에 큰 문제는 없는 수준입니다.
- **유형 분류**: 퇴근집중형 303개 역, 출근집중형 267개 역 (n = 570)

> n이 570개나 되면 p값은 거의 항상 매우 작게 나오므로, 유의성보다 계수 크기와 신뢰구간이 더 중요한 정보입니다. v2 스크립트는 이분산에 강건한 HC3 표준오차 기준 p값과 95% 신뢰구간, 표준화 계수를 함께 출력합니다.

그림은 다음 세 가지입니다. (그림은 [`src/subway_regression_analysis.py`](../src/subway_regression_analysis.py) 실행 시 로컬에 생성되며, 저장소에는 커밋되어 있지 않습니다 — 재현 방법은 저장소 루트 [README](../README.md#how-to-run) 참고.)

## 6. 통계학적/방법론적 한계점 진단 및 발전 방향 (Future Work)

본 프로젝트의 분석 신뢰도를 최상위 수준으로 방어하기 위해 다음과 같은 한계점을 투명하게 정의하고 발전 대안을 제시합니다.

- **매출 데이터로의 검증**: 현재 진열·발주 전략은 승하차 데이터에서 추론한 가설입니다. 실제 편의점 POS 매출과 연결해 유형별로 시간대 매출 구성이 다른지 확인하고, 진열 변경은 A/B 테스트로 효과를 측정해야 합니다.
- **잔차의 비정규성과 이분산**: Shapiro-Wilk 검정에서 잔차가 정규분포를 따르지 않았고, 역 규모가 클수록 잔차 폭이 커질 수 있습니다(이분산 — v2는 Breusch-Pagan 검정으로 점검). v2에서는 HC3 강건 표준오차와 로그-로그 모델 재분류(일치율 보고)를 추가했습니다. 다음 단계로 Huber 등 로바스트 회귀로 초대형 역의 영향력을 줄이는 방안을 검토합니다.
- **이분 분류의 단순화**: 잔차 0을 기준으로 한 이분 분류는 0 근처 역을 임의로 나눕니다. 경계 역(|표준화잔차| < 0.5)은 ‘중립형’으로 분리하는 3분류도 고려할 수 있습니다.
- **호선 특성별 상권 유형의 ANOVA 분산분석 심화**: 현재 모델은 전체 역사를 단일 모집단으로 간주하고 선형 회귀를 도출했으나, 실제 지하철 노선 특성(예: 업무 지구가 집중된 2호선 vs 교외 주거 단지를 잇는 경기권 국철 노선)에 따라 유동인구 펄스 구조가 상이할 수 있습니다. 차후 고도화 단계에서는 각 호선별 상권 분류군 간 유의미한 트래픽 차이가 존재하는지 검증하기 위한 ANOVA(일원분산분석) 및 Tukey's HSD 사후 검정을 도입하여 상권 타겟팅 로직을 정밀화할 계획입니다.
- **지리적 인접성에 따른 공간 상관성(Spatial Autocorrelation) 확장**: 현재 분석은 개별 역사의 지리적 위치(위경도) 정보를 상권 병합 기준으로만 활용하고 있습니다. 그러나 실제 홍대입구-합정-신촌 상권처럼 물리적으로 근접한 역사 상권들은 유동 트래픽 패턴이 상호 전이되는 동질성을 보입니다. 향후 공간 통계학 지표인 Moran's I 등을 도입하여 지리적 인접성에 따른 광역 공동 발주 클러스터 모델로 고도화하는 방향성을 수립했습니다.
